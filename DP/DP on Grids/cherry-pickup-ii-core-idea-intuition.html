Cherry Pickup II — Core Idea & Intuition

🔗 Problem

LeetCode 1463

💡 Core Idea

There are two robots moving from the top row to the bottom row simultaneously.

At every row:

  • Robot 1 can move: left, stay, or right
  • Robot 2 can move: left, stay, or right

Since both robots are always on the same row, we only need to track:

row
robot 1 column
robot 2 column

Therefore the DP state is:

dp[row][col1][col2]

State Meaning

dp[row][col1][col2] = maximum cherries that can be collected from row to the bottom when Robot 1 is at col1 and Robot 2 is at col2.

🧠 Why Do We Need 3D DP?

For normal grid DP, we might use:

dp[row][col]

But here there are two robots.

Knowing only Robot 1's position isn't enough because the future depends on where Robot 2 is as well.

For example:

Robot 1 → column 2
Robot 2 → column 5

is different from:

Robot 1 → column 2
Robot 2 → column 3

because their possible next moves and the cherries they collect are different.

So we need:

row + col1 + col2

→ 3D DP

🔄 Transitions

Each robot has 3 choices:

-1 → move left
 0 → stay in the same column
+1 → move right

Therefore:

3 choices × 3 choices = 9 transitions

For example:

Robot 1: -1
Robot 2: +1

leads to:

dp[row + 1][col1 - 1][col2 + 1]

In general:

nextCol1 = col1 + {-1, 0, +1}
nextCol2 = col2 + {-1, 0, +1}

Take the maximum among all 9 possibilities.

🍒 Counting Cherries

At the current row:

Robots are on different cells

cherries = grid[row][col1] + grid[row][col2];

Robots are on the same cell

We must count that cell only once:

cherries = grid[row][col1];

Therefore:

int cherries = grid[row][col1];

if(col1 != col2)
    cherries += grid[row][col2];

🚫 Invalid State

If either robot goes outside the grid:

col < 0

or:

col >= m

that transition is impossible.

Since we're taking a maximum, return a very small value:

-(int)1e8

This effectively means:

"Don't choose this path."

🛑 Base Case

When:

row == grid.length

both robots have moved past the last row.

There are no more cherries to collect:

return 0;

🔁 Recurrence

The overall idea is:

Current cherries
+
Maximum cherries from the next row

So:

dp[row][col1][col2]

= current cherries

+ max(
    all 9 possible next states
  )

🚀 Initial State

Initially:

Robot 1 → (0, 0)
Robot 2 → (0, m-1)

Therefore:

maxCherries(0, 0, m - 1)

is the answer.

⏱️ Complexity

Number of states:

n × m × m

Each state has only 9 transitions.

Therefore:

Time  = O(n × m²)
Space = O(n × m²)

The 9 is a constant, so it is omitted from Big-O notation.

🧩 The Pattern to Remember

Whenever you see:

Two entities moving through a grid simultaneously

ask:

What positions are needed to completely describe the situation?

Here:

Same row
+
Robot 1 column
+
Robot 2 column

Therefore:

dp[row][col1][col2]

Mental Template

Two robots
      ↓
Track both positions
      ↓
Same row because they move simultaneously
      ↓
dp[row][col1][col2]
      ↓
3 choices × 3 choices
      ↓
9 transitions
      ↓
Take maximum

⭐ Most Important Insight

The state is not "where one robot is."

It is:

The combined position of both robots.

Treat the two robots as one combined DP state. Once that is clear, the rest of the problem is almost mechanical.
