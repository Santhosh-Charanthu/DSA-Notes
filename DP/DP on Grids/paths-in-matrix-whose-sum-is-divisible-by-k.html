2435. Paths in Matrix Whose Sum Is Divisible by K

🔗 Problem

💡 Core Idea

This is normal Grid DP, but there is an extra condition:

The path's total sum must be divisible by k.

Normally, position is enough:

dp[i][j]

But here, two paths reaching the same cell with different sum remainders are different states.

Example with k = 3:

sum = 10 → remainder 1
sum = 11 → remainder 2

Even though both paths are at the same (i,j), their future possibilities are different.

So we must remember the remainder.

🧠 DP State

dp[i][j][rem]

means:

Number of paths reaching (i,j) whose current path sum has remainder rem when divided by k.

rem ranges from:

0 ... k-1

We don't store the complete sum because only sum % k matters for the final condition.

🔄 How Remainder Changes

When we move into a cell:

current remainder = rem
current cell value = grid[i][j]

new remainder becomes:

newRem = (rem + grid[i][j]) % k;

So the remainder is simply the compressed information about the sum accumulated so far.

🔁 Transitions

From (i,j), we can come from:

up   → (i-1, j)
left → (i, j-1)

Therefore:

dp[i][j][newRem]
=
dp[i-1][j][rem]
+
dp[i][j-1][rem]

where:

rem = (newRem - grid[i][j] + k) % k

In your recursive version, you're carrying the remainder backward, so you calculate:

newRem = (rem + grid[i][j]) % k;

and pass it to the previous cells.

🛑 Base Case

At (0,0), there is exactly one path.

Check whether its sum is divisible by k:

(grid[0][0] + rem) % k == 0

🎯 Final State

We start from the destination with:

totalPaths(n-1, m-1, 0, ...)

Why rem = 0?

Because we're asking:

"How many paths from the start to this destination produce a final remainder of 0?"

So the answer represents paths whose total sum is divisible by k.

⭐ Mental Picture

Normal Grid DP
     ↓
dp[i][j]
     ↓
Extra condition: sum divisible by k
     ↓
Same cell + different remainders = different situations
     ↓
Remember sum % k
     ↓
dp[i][j][remainder]

🔑 Remember this trigger:

If a path's accumulated property affects whether the final state is valid, and that property has a limited number of possible states, add it as a DP dimension.

Here:

property = sum % k
possible values = 0 ... k-1

Therefore:

dp[i][j][rem]

That's the entire idea. 🧠
