🍒 Cherry Pickup I — LeetCode 741

🔗 Problem

1. Problem Idea

We need to:

  1. Go from (0,0) → (n-1,n-1).
  2. Collect cherries.
  3. Return from (n-1,n-1) → (0,0).
  4. A cherry can be collected only once.
  5. -1 represents a blocked cell.

The difficulty is that the return trip depends on the cells visited during the first trip.

If we solve the two trips independently, we cannot know whether a cherry was already collected.

2. 🔥 Key Transformation

Instead of thinking:

Trip 1: Start → End
Trip 2: End → Start

Reverse the second trip:

Person A: Start → End
Person B: Start → End

Now think of two people moving simultaneously from the top-left to the bottom-right.

This solves the "cherry collected twice" problem because whenever both people stand on the same cell, we count its cherry only once.

3. Why 4D DP Initially?

Suppose:

Person A = (r1, c1)
Person B = (r2, c2)

Initially, it looks like we need:

dp[r1][c1][r2][c2]

But there is an important observation.

Both people start at (0,0) and move simultaneously.

Every move is either:

Down  → row + 1
Right → col + 1

Therefore:

steps taken by A = r1 + c1
steps taken by B = r2 + c2

Since both have taken the same number of steps:

r1 + c1 = r2 + c2

Therefore:

c2 = r1 + c1 - r2

So c2 is derived from the other three variables and does not need to be stored.

Therefore the 4D state becomes:

dp[r1][c1][r2]

where:

c2 = r1 + c1 - r2

🧠 Important DP principle

If a state variable can always be derived from other state variables, it is redundant and doesn't need to be stored.

4. DP State Meaning

dp[r1][c1][r2]

means:

Maximum number of cherries that can be collected when Person A is at (r1,c1) and Person B is at (r2,c2).

where:

c2 = r1 + c1 - r2;

5. 🍒 Counting Current Cherries

First calculate:

int cherries = grid[r1][c1];

If the two people are on different cells, add the second person's cherry:

if(r1 != r2 || c1 != c2)
    cherries += grid[r2][c2];

Why ||?

Same cell means:

r1 == r2 && c1 == c2

Different cells means the opposite:

r1 != r2 || c1 != c2

Therefore:

Same cell       → count once
Different cells → count both

6. 🔄 Transitions

Each person can make two moves:

Down
Right

Therefore there are:

2 × 2 = 4

possible combinations.

1. Both Down

findCherries(r1 + 1, c1, r2 + 1)

2. A Down, B Right

findCherries(r1 + 1, c1, r2)

3. A Right, B Down

findCherries(r1, c1 + 1, r2 + 1)

4. Both Right

findCherries(r1, c1 + 1, r2)

Take the maximum:

current cherries + max(4 possible next states)

7. 🚫 Invalid States

If either person's calculated position goes outside the grid:

if(r1 >= n || c1 >= n || r2 >= n || c2 >= n)
    return NEG;

Also, if either person reaches a thorn:

if(grid[r1][c1] == -1 || grid[r2][c2] == -1)
    return NEG;

where:

NEG = -(int)1e9;

Why negative infinity?

We're taking max().

An invalid path should never be selected over a valid path.

So:

valid path       → positive/normal value
invalid path     → very negative value

8. 🛑 Base Case

When Person A reaches:

(n-1, n-1)

Person B must also be there.

Why?

Because:

r1 + c1 = r2 + c2

At the destination:

r1 + c1 = 2n - 2

The only cell whose row + column equals 2n - 2 is:

(n-1, n-1)

Therefore:

if(r1 == n-1 && c1 == n-1)
    return grid[r1][c1];

9. 🧠 Recurrence

The entire recurrence can be remembered as:

Answer for current state
=
Cherries at current positions
+
Maximum of the 4 possible next states

Conceptually:

dp[r1][c1][r2]

= current cherries

+ max(
    DD,
    DR,
    RD,
    RR
  )

10. Why Memoization?

The same state can be reached through different combinations of paths.

For example, different paths may eventually bring both people to:

(r1, c1, r2)

Once we calculate the answer for that state, we don't need to calculate it again.

if(dp[r1][c1][r2] != INF)
    return dp[r1][c1][r2];

Then store:

return dp[r1][c1][r2] = answer;

11. Initial State

Both people start at (0,0) after reversing the second trip.

Therefore:

findCherries(0, 0, 0, ...)

is the initial state.

12. Complexity

There are:

n × n × n

possible states.

Each state has 4 transitions.

Therefore:

Time  = O(n³)
Space = O(n³)

The 4 transitions are a constant factor.

⭐ The Most Important Chain to Remember

Don't memorize the code.

Remember this derivation:

Two trips
   ↓
Trips interact because cherries cannot be collected twice
   ↓
Reverse the return trip
   ↓
Think of two people moving Start → End
   ↓
Need both people's positions
   ↓
Initially 4 coordinates
   ↓
Both move simultaneously
   ↓
r1 + c1 = r2 + c2
   ↓

   ↓
3D DP: dp[r1][c1][r2]
   ↓
Each person has 2 choices
   ↓

   ↓

   ↓

🧠 Revision Trigger

When you see "go there, come back, and don't collect the same item twice", immediately ask:

"Can I reverse the return trip and model it as two simultaneous travelers?"

That single question is the key to rediscovering Cherry Pickup I instead of memorizing it.
