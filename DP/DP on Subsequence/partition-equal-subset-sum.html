416. Partition Equal Subset Sum

🔗 Problem

🧠 Intuition

We need to divide the array into two subsets such that both subsets have equal sum.

Instead of thinking about two subsets, think about finding one subset.

If one subset has sum totalSum / 2, the remaining elements will automatically have the same sum.

Therefore, the problem reduces to a Subset Sum problem.

🔍 Key Observation

Let:

Subset 1 = S1
Subset 2 = S2

Since every element belongs to exactly one subset:

S1 + S2 = totalSum

For an equal partition:

S1 = S2

Substituting,

2 × S1 = totalSum

Therefore,

S1 = totalSum / 2

So, we only need to determine:

Is there a subset whose sum equals totalSum / 2?

📐 Mathematical Derivation

Given,

S1 + S2 = totalSum

For equal partition,

S1 = S2

Substitute S2 with S1:

S1 + S1 = totalSum

2 × S1 = totalSum

S1 = totalSum / 2

Hence,

If a subset with sum totalSum/2 exists,
the remaining elements also sum to totalSum/2.
🔍Observation

If

totalSum is odd

then,

totalSum / 2

is not an integer.

Therefore, it is impossible to split the array into two equal subsets.

Return:

false

immediately.

🎯 DP Reduction

The original problem becomes:

Can we find a subset with sum = totalSum / 2 ?

This is exactly the Subset Sum Equal to Target problem.

State:

solve(i, target)

= Is it possible to form the remaining target
  using elements from index 0 to i?

Transition:

take || notTake

🧩 Pattern Recognition

Whenever you see:

  • Partition into two equal subsets
  • Equal partition
  • Equal sum partition

Immediately think:

Compute totalSum

↓

If totalSum is odd → False

↓

Target = totalSum / 2

↓

Solve using Subset Sum DP

💡 One-Line Memory Trick

Equal Partition = Subset Sum(totalSum / 2)

O(N × totalSum)
💾Space Complexity
O(N × totalSum)
