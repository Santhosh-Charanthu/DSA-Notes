Problem: Cycle Detection in a Directed Graph

🧠Intuition
  • In a directed graph, edges have a fixed direction.
  • Unlike an undirected graph, reaching a previously visited node does not always mean a cycle because that node may already be completely processed.
  • A cycle exists only if we reach a node that is currently in the DFS recursion path.
  • Therefore, maintain two arrays:
    • visited[] → Node has been visited at least once.
    • pathVisited[] → Node is part of the current DFS path (recursion stack).

How to Think

  • During DFS, every recursive call extends the current path.
  • Mark a node in pathVisited when entering it.
  • Remove it from pathVisited when backtracking.
  • If during traversal we encounter a neighbour already present in pathVisited, we have returned to an ancestor, forming a cycle.

Algorithm (DFS)

  1. Create two arrays:
    • visited[]
    • pathVisited[]
  2. For every unvisited node:
    • Start DFS.
  3. Mark:
    • visited[node] = true
    • pathVisited[node] = true
  4. Traverse all neighbours.
  5. If a neighbour is unvisited:
    • Recursively call DFS.
  6. If a neighbour is already in pathVisited, return true.
  7. Before returning from DFS:
    • Set pathVisited[node] = false (backtracking).
  8. If no cycle is found after traversing all components, return false.

Why It Works

  • visited[] prevents revisiting already explored nodes.
  • pathVisited[] represents the current DFS path.
  • If DFS reaches a node already in the current path, there is a path from that node back to itself.
  • This forms a back edge, which is the defining property of a cycle in a directed graph.
⏱️Time Complexity
  • Time: O(V + E)
  • Space: O(V) (visited array + recursion stack + pathVisited array)

Interview Recognition Pattern

Use this approach when:

  • The graph is directed.
  • You need to detect whether a directed cycle exists.
  • Problems involving prerequisites, dependencies, workflows, or task scheduling.

Key Observation:

  • Visited neighbour = Not necessarily a cycle ❌
  • Neighbour currently in recursion path = Cycle ✅

Alternative Method (Topological Sort - Kahn's Algorithm)

  • Compute the indegree of every node.
  • Push all nodes with indegree 0 into a queue.
  • Perform Topological Sort.
  • Count how many nodes are processed.
  • If processedNodes < totalNodes, a cycle exists.

Why?

  • A Directed Acyclic Graph (DAG) always has at least one node with indegree 0.
  • If a cycle exists, the nodes in the cycle keep each other's indegree above 0, so they can never be processed.
  • Hence, not all nodes appear in the topological order.

When to Use Which?

DFS + Recursion Stack

  • Direct cycle detection.
  • Easier to understand and implement.
  • Common in interview coding rounds.

Kahn's Algorithm (BFS)

  • Useful when the problem also asks for Topological Sort.
  • Detects cycles without recursion.
  • Common in Course Schedule and dependency graph problems.

Key Difference from Undirected Graph

Undirected Graph Directed Graph
Track Parent Track Recursion Path (pathVisited)
Ignore the edge to the parent Detect a Back Edge
Visited neighbour ≠ Parent ⇒ Cycle Neighbour in current DFS path ⇒ Cycle

Memory Trick

Directed Graph: A cycle exists only if you come back to a node that is still in the current DFS recursion path (Back Edge). Once a node is fully processed and removed from the recursion stack, visiting it again does not form a cycle.
