Word Ladder II

🧠Intuition
  • This problem is an extension of Word Ladder I.
  • Instead of finding only the shortest length, we need all shortest transformation sequences.
  • BFS is still used because it discovers words level by level, ensuring the shortest distance.
  • However, we cannot remove a word immediately after visiting it because another path in the same BFS level might also reach that word with the same minimum distance.
  • Therefore:
    • BFS computes the shortest distance (or builds parent relationships).
    • Backtracking/DFS reconstructs all shortest paths.

How to Think

  • Think of each word as a graph node.
  • We only care about paths that belong to the shortest level graph.
  • During BFS:
    • Record the minimum level (distance) of every word.
    • Record all possible parents that reach a word at the same minimum level.
  • Once BFS reaches endWord, use DFS/backtracking to reconstruct every shortest sequence.

Algorithm (Recommended Approach: BFS + DFS)

Phase 1: BFS (Build Shortest-Level Graph)

  1. Store all words in a HashSet.
  2. Start BFS from beginWord.
  3. Maintain:
    • distance[word] → shortest level from beginWord.
    • parents[word] → all previous words that can reach this word in the shortest path.
  4. For every generated neighbour:
    • If visited for the first time:
      • Set its distance.
      • Add current word as its parent.
      • Push into queue.
    • Else if reached at the same shortest level:
      • Add current word to its parent list.

Phase 2: DFS (Construct Paths)

  1. Start from endWord.
  2. Recursively move through its parents.
  3. Continue until reaching beginWord.
  4. Reverse the current path and store it.

Alternative Approach (Queue Stores Entire Paths)

Another accepted approach stores the entire transformation path in the BFS queue.

🧾Algorithm
  1. Queue stores List<String> instead of a single word.
  2. At each BFS level:
    • Extend every path by one valid transformation.
  3. Remove visited words only after finishing the entire level.
  4. Once endWord is found:
    • Finish processing the current level.
    • Stop BFS.
  5. All collected paths are guaranteed to be the shortest.

Why Can't We Remove a Word Immediately?

Example:

hit
 |
hot
/   \
dot lot
 \   /
 dog

Suppose both dot and lot can reach dog in the same BFS level.

If dog is removed immediately after dot reaches it:

dot → dog ✔
lot → dog ✘ (blocked)

We lose one valid shortest path.

Instead:

  • Finish the entire level.
  • Then remove all words visited in that level.

This allows multiple shortest paths to share intermediate words.

Why It Works

  • BFS guarantees the first time a level is reached is the shortest distance.
  • Recording all parents at the same level preserves every shortest route.
  • DFS only traverses edges belonging to the shortest-level graph.
  • Hence, every generated sequence is shortest, and no shortest sequence is missed.
⏱️Time Complexity

Let:

  • N = Number of words
  • L = Length of each word

BFS

  • Time: O(N × L × 26)

DFS

  • Depends on the number of shortest paths.
  • In the worst case, output size can be exponential.

Overall:

  • Time: O(N × L × 26 + Output Size)
  • Space: O(N + Output Size)

Interview Recognition Pattern

Use this approach when:

  • You need all shortest paths, not just one.
  • The graph is unweighted.
  • Multiple shortest routes may exist.
  • The problem asks for the actual sequences instead of only the distance.

Difference from Word Ladder I

Word Ladder I Word Ladder II
Return shortest length Return all shortest sequences
Mark visited immediately Delay removal until level ends (or store multiple parents)
BFS only BFS + DFS (or BFS storing full paths)
Stop immediately when end is found Finish current BFS level, then stop
🔍Key Observation
  • Word = Node
  • One letter change = Edge
  • Shortest paths only = BFS levels
  • Multiple shortest paths = Record all parents or delay removal

Memory Trick

Word Ladder I asks "How far?" → BFS.
Word Ladder II asks "Show every shortest way." → BFS builds the shortest graph, DFS reconstructs every path.
