Floyd-Warshall Algorithm

🎯 What is it?

Floyd-Warshall is an All-Pairs Shortest Path (APSP) algorithm.

  • Finds the shortest distance between every pair of vertices.
  • Works with positive and negative edge weights.
  • Can detect negative-weight cycles.

🧠 Core Intuition

For every pair of vertices i → j, ask:

"Can I get a shorter path from i to j by going through vertex k?"

Compare:

Direct/current path:
i ─────────→ j

Path through k:
i ──→ k ──→ j

So:

dist[i][j] = min(
    dist[i][j],
    dist[i][k] + dist[k][j]
)

🔄 Why k → i → j?

for (int k = 0; k < V; k++)
    for (int i = 0; i < V; i++)
        for (int j = 0; j < V; j++)
  • k → intermediate vertex we are currently allowing
  • i → source
  • j → destination

The algorithm gradually allows every vertex to become an intermediate vertex.

k = 0 → allow vertex 0 as intermediate
k = 1 → allow vertices 0,1
k = 2 → allow vertices 0,1,2
...
k = V-1 → allow all vertices

📌 Why does it work?

Any shortest path can be viewed as:

i → ... → k → ... → j

So when considering k, we have only two choices:

  1. Don't use k → keep dist[i][j]
  2. Use k → dist[i][k] + dist[k][j]

Take the minimum.

⚠️ Negative Cycle Detection

Initially:

dist[i][i] = 0

After running Floyd-Warshall:

if (dist[i][i] < 0)
    // negative cycle exists
🧠Intuition

If the distance from a vertex back to itself becomes negative:

i → ... → i < 0

then there is a negative-weight cycle.

⏱️ Complexity

Three loops, each running V times:

V × V × V = O(V³)

Time: O(V³) Space: O(V²)

🎤 Interview One-Liner

"Floyd-Warshall finds shortest paths between every pair of vertices by checking whether each vertex can serve as an intermediate point that gives a cheaper path between the source and destination."

🧠 Memory Trick

Floyd-Warshall = Every pair + Every intermediate vertex
