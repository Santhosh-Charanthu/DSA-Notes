LeetCode 1760 — Minimum Limit of Balls in a Bag

🔗 Problem

1. Why this comes under Binary Search on Answers

We need to minimize the maximum number of balls in any bag after performing at most maxOperations split operations.

We are not searching for the answer inside the array. We are searching over possible values of the maximum allowed bag size.

For a candidate mid:

  • If we can make every bag have at most mid balls using <= maxOperations operations → mid is possible.
  • If we need more than maxOperations operations → mid is too small.

The feasibility pattern is:

FALSE FALSE FALSE TRUE TRUE TRUE

So this is Binary Search on Answer → Minimize the Maximum → First TRUE.

2. What is the answer I'm searching for?

We are searching for the minimum possible maximum number of balls in any bag.

mid = maximum number of balls allowed in one bag

Example:

nums = [9]

If:

mid = 5

we can split:

9 → 5 + 4

So the largest resulting bag has 5 balls.

We want the smallest possible value of that maximum.

3. What is the smallest possible answer?

1.

With enough operations, every bag can eventually contain only one ball.

Therefore:

low = 1

4. What is the largest possible answer?

max(nums).

If we perform zero operations, the largest bag contains max(nums) balls.

We never need an answer larger than that.

Therefore:

high = max(nums)

So:

1 <= answer <= max(nums)

5. If I assume mid is the answer

Assume:

mid = maximum allowed balls in each bag

For every original bag containing num balls, determine how many pieces are required so that every piece contains at most mid balls.

Number of pieces:

ceil(num / mid)

If we create pieces pieces from one bag, the number of split operations required is:

pieces - 1

Add this for every bag.

If operations <= maxOperations

We can achieve maximum bag size mid.

So mid is possible.

But we want the minimum possible maximum size, so try a smaller value:

high = mid - 1

If operations > maxOperations

We don't have enough operations to make bags this small.

So mid is too small:

low = mid + 1

Therefore:

possible → LEFT

not possible → RIGHT

We are looking for the first TRUE.

6. Main idea of isPossible()

For a candidate mid:

  1. Take each bag independently.

  2. Calculate how many pieces are needed if every piece can contain at most mid balls:

    pieces = ceil(num / mid)

  3. Splitting one bag into pieces requires:

    pieces - 1 operations

  4. Add the operations required for all bags.

  5. Check whether the total operations are within maxOperations.

Example

nums = [9, 7, 5]

Suppose:

mid = 5

For 9:

ceil(9/5) = 2 pieces

Operations:

2 - 1 = 1

For 7:

ceil(7/5) = 2 pieces

Operations:

1

For 5:

ceil(5/5) = 1 piece

Operations:

0

Total:

1 + 1 + 0 = 2 operations

Therefore, if:

maxOperations >= 2

then mid = 5 is feasible.

Key mathematical idea

For a bag containing num balls:

required operations = ceil(num / mid) - 1

This directly tells us how many splits are needed; no simulation of individual splits is required.

7. Main intuition

Simple idea

We don't know the smallest possible maximum bag size, so guess it as mid.

Then ask:

"Can I split all bags so that no bag contains more than mid balls using the allowed number of operations?"

For every bag, calculate how many splits are necessary.

If the total number of operations is within the limit, mid works → try smaller.

If we need too many operations, mid is too small → try larger.

In one flow

Answer = minimum possible maximum bag size

→ Search in [1, max(nums)]

→ Assume mid is the maximum allowed bag size

→ For every bag calculate ceil(num / mid) - 1

→ Add required operations

→ operations <= maxOperations → possible → go LEFT

→ operations > maxOperations → impossible → go RIGHT

→ Return the first feasible value

Pattern to remember

Minimize the Maximum → Binary Search on Answer → First TRUE → if mid works, move LEFT.

⭐Important implementation points

  • One operation splits one bag into two bags.

  • If a bag needs pieces pieces, it requires exactly pieces - 1 operations.

  • low = 1 because every bag can theoretically be reduced to individual balls.

  • high = max(nums) because doing zero operations gives the largest possible bag size.

  • The total number of operations can exceed int, so using long for operations is important.

  • Integer arithmetic can replace Math.ceil():

    (num + mid - 1) / mid
