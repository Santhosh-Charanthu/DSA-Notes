LeetCode 69 — Sqrt(x)

🔗 Problem

1. Why this comes under Binary Search on Answers

We are not searching for an element in a sorted array. We are searching for the largest possible answer mid such that:

mid * mid <= x

For increasing values of mid, the condition changes monotonically:

TRUE TRUE TRUE TRUE FALSE FALSE FALSE

So this is Binary Search on Answer → Maximum Feasible Value / Last TRUE.

2. What is the answer I'm searching for?

The largest integer mid whose square is ≤ x.

In other words:

answer = floor(sqrt(x))

Example:

x = 10

1² ≤ 10 ✅
2² ≤ 10 ✅
3² ≤ 10 ✅
4² ≤ 10 ❌

Answer = 3.

3. What is the smallest possible answer?

0, because sqrt(0) = 0.

In the implementation, we start with:

low = 1

because 0 can be handled separately / the loop can simply search positive candidates.

4. What is the largest possible answer?

x.

For positive x, sqrt(x) <= x.

Therefore:

low = 1
high = x

5. If I assume mid is the answer

Assume mid is the candidate square root.

Check:

mid * mid <= x

If mid * mid <= x

mid is a valid answer.

But we want the largest valid value, so try a bigger value:

low = mid + 1

Save mid as the current answer.

If mid * mid > x

mid is too large, so search left:

high = mid - 1

Therefore:

possible → RIGHT
not possible → LEFT

We are looking for the last TRUE.

6. Main idea of isPossible()

For a candidate mid, simply check whether:

mid * mid <= x

If this condition is true, mid is a valid answer.

If it is false, mid is too large.

There is no separate loop or greedy calculation needed for the feasibility check; the condition itself tells us whether mid is possible.

6. Main intuition

Simple idea

Guess a number mid and ask:

"Is mid a valid square root?"

If mid² <= x, it works, so try a bigger number.

If mid² > x, it is too large, so try a smaller number.

The last number that works is the answer.

In one flow

Answer = largest valid number

→ Search in [1, x]

→ Assume mid is the answer

→ Check mid² <= x

→ YES → mid works → go RIGHT

→ NO → mid is too large → go LEFT

→ Return the last feasible value

Pattern to remember

Maximum feasible answer = Last TRUE → if mid works, move RIGHT.

⭐Important implementation point

Use long for mid and mid * mid because mid * mid can overflow int for large x.
